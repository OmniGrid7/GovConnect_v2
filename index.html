System Architecture — SIH26129

Two-phase AI engine running on verified Maharashtra government scheme data.

Maharashtra Govt Platforms ┌─────────────┬─────────────┬─────────────┐ │ Education │ Agriculture │ Employment │ └─────────────┴─────────────┴─────────────┘ | API Gateway | Data Normalization | Government Service DB ← 15 verified schemes | ┌──────────────┴──────────────┐ │ │ Eligibility Engine AI Matching Engine (Phase 1: rule-based) (Phase 2: Sentence Transformers) • Income check • paraphrase-multilingual-MiniLM • Age check • TF-IDF + cosine similarity • Category check • Language detection (EN/HI/MR) • Gender check • Query expansion via glossary • Area check • Weighted score blending │ │ └──────────────┬──────────────┘ | Ranking Engine (40% TF-IDF + 60% Semantic + Eligibility boost) | Explainable Results (matched rules, missing docs, score bars) | Citizen Portal (Flask + HTML, no login required)

✅ Phase 1 — Working Prototype

  • Verified scheme metadata (15 real Maharashtra schemes)
  • Normalized scheme database (JSON)
  • Rule-based eligibility engine
  • TF-IDF recommendation with bigrams

✅ Phase 2 — Better AI

  • Sentence Transformers (multilingual MiniLM)
  • Marathi, Hindi and English support
  • Entity extraction via query expansion glossary
  • Weighted semantic + TF-IDF score blending

🔧 Phase 3 — Interoperability (Planned)

  • Connect approved departmental APIs
  • Common API/data model across departments
  • Service discovery across Maharashtra portals
  • Status tracking where APIs permit

🔒 Phase 4 — Production Grade (Planned)

  • Role-based access control
  • Encryption + secure authentication
  • Consent and data minimization
  • Audit logs + model drift monitoring
